# The AI trace harness — same-seed number comparison (Phase 2)

Date: 2026-10-08. Companion to `docs/2026-10-08-ai-completion-plan.md`
(Phase 2). The harness dumps the remake's AI state per turn as text so the
original's numbers can be diffed field by field; the first divergence names
the turn and the field. All code lives in `src/ai_trace.c` + `src/ai_trace.h`;
`src/main.c` carries only the include and two hook calls in
`AdvanceToNextPlayer`.

## Enabling the trace

The dump is compiled in only when `AI_TRACE` is defined; normal builds are
untouched (the file compiles to an empty translation unit).

```bash
cd src
make PLATFORM=powerpc AI_TRACE=1          # trace build (warlords2_ppc)
MakePEF warlords2_ppc -o warlords2.pef    # as usual; push_remake.sh --build
make PLATFORM=powerpc                     # rebuild without: committed binaries stay normal
```

Or `#define AI_TRACE 1` before including `ai_trace.h` / on the compiler
command line (`-DAI_TRACE`) — the Makefile flag is the intended path.
`tools/infinitemac/devloop/push_remake.sh --build` builds with the default
(off); pass a trace build by exporting `AI_TRACE=1` there or building first
and pushing with `--no-build`.

## Where the file lands

`aitrace.txt` in the app's working directory, append mode, flushed (via
`fclose`) once per record. To get it out of the emulator, copy it into
`The Outside World:Uploads` in the Mac — the bridge extracts it to
`.devloop/pulled/<name>/` (see `tools/infinitemac/devloop/README.md`).
Delete it between runs (or rename the pulled copy) so runs don't mix.

## Record format

One line per item, stable field order, greppable tags. `<s>` is the side
whose turn just ran; the dump is a full-world snapshot taken right after
`ExecuteAITurn(side)` returns.

    R<n> BEGIN
    T<s> TURN <n> GOLD <g> INC <i> UPK <u> SEED <seed>
    T<s> DIP <a> <b> E<eff_ab><eff_ba> P<prop_ab><prop_ba>
    T<s> CITY <ci> OWN <o> ROLE <r> CF <f> U <uc> P <pc> PROD <p> PRG <t> S <s0> <s1> <s2> <s3>
    T<s> ARMY <i> XY <x> <y> OWN <o> T <t0> <t1> <t2> <t3> MP <mp> ORD <ty> <tg> <fr> <gr> <flags> <dx> <dy>
    T<s> END

- `R<n> BEGIN` — written once per round, after the round bookkeeping (turn
  counter increment, elimination, neutral production, history snapshot) and
  just before the next side's start-of-turn processing, so the human turn
  boundary is visible. `<n>` is `gs+0x136`, the round counter.
  (The per-round-file emitter, `aitrace4_r<n>.txt`, no longer writes this
  line: the round is in the file name and in every `T<s> TURN <n>` header.
  `tools/ai_trace_diff.py` attributes CITY lines to the side's latest TURN
  header, so it works with or without the marker. The pulled `aitrace3_r*`
  files also lack side 1's TURN line; see `tests/python/`.)
- `T<s> TURN ...` — header line: round `<n>`, gold `gs+0x186+side*0x14`,
  income/upkeep as fixed at the side's turn start (`sAIIncomeAt` /
  `sAIUpkeepAt`, the remake's DAT_3bc00000 / DAT_2c9d0000), and the
  QuickDraw `randSeed` at dump time (Toolbox Random state; the seed is
  never saved with a game, so same-seed runs need a fixed launch seed).
- `T<s> DIP <a> <b> ...` — all 28 unordered pairs per dump: effective
  stance (bits 0-1 of the byte at `gs+0x1582+a*8+b`, and of the mirrored
  byte) and proposed stance (bits 2-3) in both directions. 0 peace
  1 hostile 2 war.
- `T<s> CITY <ci> ...` — every city index `0..sCityCount-1` (aligned rows
  across turns): owner (city record +0x04), the AI block's role, cflags,
  unitCount, poolCount for the city, production type (ext city +0x02,
  -1 none), production progress in turns left (ext city +0x58), and the
  four production slot types (ext city +0x06..+0x0d, -1 empty).
- `T<s> ARMY <i> ...` — every army record `0..count-1` (gs+0x1602): x/y
  (record +0x00/+0x02, negative = off map in vectoring transit), owner
  (+0x15), the four unit types (+0x16..+0x19, 0xFF empty), moves (MP,
  +0x2e), and the per-record orders word as separate fields: type, target,
  front, group, flags (hex, the u32's high half), destX, destY
  (`AIOrder` in main.c, the remake of unit+0xc). `-` when the orders mirror
  is unavailable.
- `T<s> END` — end of the side's record.

Example grep use: `grep "T3 CITY 17 " aitrace.txt` prints that city's line
for every dumped turn of side 3 — production, garrison and role history in
order.

## Running a same-seed game

The launch loop is the devloop one (tools/infinitemac/devloop/README.md):

1. Build with `AI_TRACE=1`, `push_remake.sh --no-build` (or `--build` with
   `AI_TRACE=1` exported), `relaunch_remake.sh` to run it.
2. Drive the same scenario+seed: the original's recordings
   (`.devloop/movies/fullgame_orig.mp4`, `wingame_orig.mp4`) are the
   reference; the same scenario started with the same launch seed and the
   same player input reproduces the AI's decisions. `qd.randSeed` is seeded
   from `GetDateTime` at launch (main.c, PPC FUN_1005f32c), so to pin the
   seed, launch the trace build and note the `SEED` field of the first
   record — replaying at the same wall-clock seed means relaunching and
   comparing that line first.
3. Play to the target round, quit (Cmd-Opt-Q is the devloop quit), copy
   `aitrace.txt` out via Uploads.

Headless-ish alternative: the devloop bridge runs the emulator headless
(`node tools/infinitemac/devloop/bridge.mjs --headless`), and
`scripts/*.json` step scripts drive setup + end turns
(e.g. `endturns_12.json`) without screenshots.

## Diffing against the original's numbers

The Isles recordings' info panel is the reference for gold / income /
upkeep / cities per round (`fullgame_log.md` in `.devloop` logs the
per-round readings). For each round, find the trace lines:

    grep "T<s> TURN <n> " aitrace.txt     -> gold, income, upkeep
    grep -c "OWN <s> " on CITY lines      -> city count per side (or
    grep "T<s> CITY " aitrace.txt | grep "OWN <s>$" | wc -l)

and compare with the recorded panel values for that round. A mismatch names
the side, the round and the field; the CITY/ARMY/DIP lines of that same
round then locate the decision that diverged (production choice, stack
position, stance). `tools/ai_trace_diff.py` automates the comparison: give
it the trace and the reference numbers as `round,side,field,value` lines
(or a log excerpt) and it prints the first diverging field per round.
